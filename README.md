# AI命理 · 移动端交互 Demo

React + Vite + TypeScript + Tailwind CSS，393 × 759 移动端画布。页面内容可滚动，导航及弹窗为真实组件；没有把整张设计稿当页面背景。

## 启动

使用 Node.js 20.19+ 或 22.12+，在此文件所在目录执行：

```bash
npm install
npm run dev
```

打开终端显示的地址（默认 http://localhost:5173）。手机与电脑处于同一网络时，可使用终端显示的 Network 地址访问。桌面居中显示 393 × 759 画布；窄屏适配屏幕宽度。

```bash
npm run build
npm run preview
```

构建输出位于 `dist/`，应通过 HTTP 服务预览，而不是双击 `index.html`。

## 已实现交互

- 首页：今日解读入口、事业/感情/财富展示卡片（不跳转）、四个命理解读入口、幸运签入口。
- 今日解读：运势详解、行动建议、收藏和分享。收藏保存在 localStorage；不支持系统分享时尝试复制链接。
- 本命星盘：八字命盘、完整四柱表格、章节切换、占卜星盘占位说明。
- 马年运势：生肖太岁、锁定报告、模拟解锁、开运建议等章节。无支付接口，不扣费。
- 缘分分析：命主信息、四柱命盘及章节切换。
- 命主资料：编辑姓名、性别、出生时间、地点，刷新后保留。不会根据新资料重新计算命盘。
- 幸运壁纸：左右滑动、箭头和圆点切换、壁纸馆、PNG 下载。浏览器无法直接写入系统相册，需在下载列表中另存到相册。
- 幸运签：签筒/按钮触发动画、展示签文、再抽一次、关闭返回。签文按示例列表轮换。
- 弹窗：关闭、Escape、焦点约束、背景禁用；页面路由支持浏览器返回和 hash 链接。

## 设计依据与边界

按对话中最终首页及详情图进行视觉还原。之前的在线 Figma 文件没有完整页面，因此本项目不是从已完成的 Figma 节点导出。字体使用系统中文字体；不同操作系统字形会略有差异。星球、签筒和莲花壁纸为独立生成素材，其余图标和壁纸为 SVG；不是截图上的不可交互切片。

已提供的命主信息、运势分数与四柱内容保留为固定演示数据；未给出详细内容的标签页明确标记「演示内容」。没有账号、真实排盘、付费或后端服务。
